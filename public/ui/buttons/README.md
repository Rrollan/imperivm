# Текстуры кнопок и фриза

Положите сюда PNG с точными именами. UI подхватит их без изменения кода.
Все надписи и иконки интерфейса остаются в коде, включая RU/EN.
Не запекайте текст в изображения. Пока файлов нет, под ними виден CSS-фолбэк.

| Файл | Назначение | Рекомендуемый размер |
| --- | --- | --- |
| `tablet-normal.png` | Широкая каменная / чеканная табличка | 600×180 |
| `tablet-hover.png` | Наведение на табличку | 600×180 |
| `tablet-pressed.png` | Нажатая табличка | 600×180 |
| `tablet-disabled.png` | Неактивная табличка | 600×180 |
| `medallion-normal.png` | Круглый медальон силы героя | 256×256 |
| `medallion-disabled.png` | Неактивный медальон | 256×256 |
| `icon-button.png` | Квадратная каменная кнопка / контрол фриза | 128×128 |
| `frieze.png` | Каменный архитрав, бесшовный по горизонтали | 1024×128 |

У состояний таблички одинаковые размеры и внутренние поля. Текстуры растягиваются
по размеру контрола; оставьте спокойную середину для текста. Медальоны делайте
с прозрачными углами. Фриз повторяется по горизонтали, высота масштабируется
под архитрав. Изображения декоративные, фокус клавиатуры рисуется CSS.

Исходные монеты и 3D-арт силы героя остаются поверх текстуры медальона.
После замены ассетов проверяйте читаемость текста, контраст и все состояния.
В dev достаточно обновить страницу; production-поставку пересобрать и обновить
кэш статики обычным способом. Новые файлы не требуют правок modelManifest.ts.

При успешной загрузке `tablet-normal.png` интерфейс автоматически включает светлый
DOM-текст на табличках: центр поставленных текстур должен быть тёмным. Без PNG
сохраняются золотой CSS-фолбэк и тёмный текст. Непрозрачные белые поля изображений
смешиваются с основанием через CSS; для следующих поставок предпочтителен настоящий
alpha-канал. Фриз использует центральную полосу текстуры. Дополнительные `gate-*.png`
в эту поставку слотов не входят и текущим меню не используются.
