# IMPERIVM action-status medallions v2

Generated with the built-in imagegen tool on 2026-10-09. The original transparent PNG is copied into this project; its alpha is preserved. No API/CLI fallback was used.

The game serves `action-medallions.webp`, a 640×640 optimized derivative with preserved alpha, encoded locally with cwebp quality 90 / alpha quality 100. Each 320px cell exceeds the Retina needs of these small battlefield status icons. The original PNG remains available for reuse.

`action-medallions.png` is a 1254×1254 two-by-two atlas. Top left: attack ready, upright gladius on burgundy. Top right: waiting/fresh/no legal target, hourglass on amber. Bottom left: spent/over, lowered sword on charcoal. Bottom right: staking, padlock on turquoise. `ArenaTextures.drawStatus` draws equal quadrants without distorting their circular silhouettes. The status always follows engine-derived readiness. The existing vector symbols remain the loading fallback and DOM controls.
