# Native card inspection, 6 October 2026

Scope: `/arena-lab`. All 43 card IDs and their rules are preserved. README.md, CardView.tsx, card-frames.css and ManaCrystals.tsx remain untouched. The older `/game` renderer is unchanged.

## Changes

- One animated, focus-managed inspection surface for hand cards, battlefield fighters, rulers, abilities, orders, clocks, the deck and the edict queue. The AI and presentation clock pause while it is open. Close/Escape restores focus; legal actions use the existing session dispatcher.
- The actual hand face is also the inspection and opening-hand face. A single 384×672 canvas painter uses a vertical illustration aperture, a generated bronze/leather frame, a blue cost hexagon, gold attack shield and red health drop. Illustration aspect ratio is preserved; no wide dark mat is used. Rules sit in a separate readable parchment strip and actions use the existing carved command button.
- Settings buttons are centered inside the centered modal. A solid layered border replaces CSS `ridge` corner wedges. Only the settings body scrolls, keeping the title and close button visible.
- Orders stones sit inside the existing bronze socket rims. The renderer compensates for the rectangular HUD texture's aspect ratio, uses measured socket centers for each board, and tints the same gem gold for a bonus. A large separate plus-disc is removed. The portrait hand has a clear gap beneath the sockets. The wide board now has ten actual wells instead of nine.
- Builder uses a front-facing medallion in both inspection and its board socket, avoiding the old off-center photograph/crop and its second live GLB. Other rulers still use their existing portraits/models and need the same front-view asset treatment.
- Delayed edicts retain their own source/target outcomes and stat contacts. Fixed 18-slot glyph/number pools are reused between source windows. No-op edicts still receive a resolution window; repeated Rug Pull does not destroy the same fighter twice. Reduced motion retains 70 outcomes in the 10-Audit regression scenario. Supplemental sprite clips get two slots per source and fit their whole source sequence into that source's display window.

## Validation limits

The effect fixtures use legal GameSession actions from deterministic initial states. They verify rule outcomes, source ordering and renderer schedules; they do not establish frame rate or subjective final visual quality. Earlier narrow-browser samples include cold stalls, so this change does not claim a universal 60 FPS. Full browser action/size checks and final build results are recorded below after verification.
