# IMPERIVM / Olympus 18–25

8 новых роликов. Они ещё НЕ подключены: сейчас игра использует процедурные эффекты и объёмное появление карты.

Omni Flash: 16:9, 720p, 4 секунды. Для каждого номера прикрепите ровно две картинки: NN-START.png как Image1 и NN-END.png как Image2. Вставьте весь NN-PROMPT.txt. Камера неподвижна, фон чёрный; звук добавляет игра. Первые 0.65–1.55 с — действие, затем чистый чёрный кадр. Не растягивайте действие на все 4 секунды.

18 — Зевс/молния; 19 — Афина/защита; 20 — Аид/разлом; 21 — печать выхода дорогой карты; 22 — тяжёлое рассечение; 23–25 — короткие появления персонажей.

Сохраните восемь результатов под именами из PROMPT и пришлите одним ZIP. Не запекайте в ролики поле, интерфейс, цифры и сами карточки.

Импорт после визуальной проверки: node scripts/vfx/atlas.mjs ID /absolute/path/ID.mp4 0 ACTIVE_SECONDS. Скрипт сохраняет атлас и manifest. Для 23–25 допустимо до 1.6 с, для обычного удара — до 1 с. Нельзя ускорять 4-секундное действие целиком: нарушается читаемость.
