# IMPERIVM — пакет для Gemini Omni Flash

Нужны восемь новых роликов 10–17. Эффекты 01–09 уже получены и подключены.
Кадры соответствуют текущей простой рамке карт: видео добавляет короткий
цветной акцент, а перемещение карты, посадку, цифры и попадание рисует игра.

## Что делать

1. Открой папку нужного эффекта.
2. Прикрепи `NN-START.png` первым изображением, `NN-END.png` вторым.
3. Вставь весь текст `NN-PROMPT.txt`. Он явно назначает Image1 первым,
   Image2 последним кадром. Если интерфейс имеет отдельные First/Last поля,
   используй их с теми же изображениями.
4. Выбери горизонтальный формат 16:9 и 720p. Целевая длина — 4 секунды,
   если её можно выбрать; иначе используй короткую доступную длину.
   Эффект всё равно должен завершиться за первые 0,42–0,65 секунды.
5. Сохрани MP4 с точным именем из `OUTPUT.txt` внутри этой папки.

Генерируй каждую папку отдельным роликом. Дополнительные референсы не нужны.
Можно начать с 12 (предводитель) и 17 (лечение), затем сделать остальные.

Чёрный фон — рабочий фон для наложения в игре. Он не должен превращаться
в сцену, серую дымку или белый диск. Центр эффекта остаётся пустым:
портрет и значения карты должны читаться сквозь него. Камера неподвижна,
эффект не расширяется на весь экран, последний кадр полностью чёрный.
В ролике нет карт, людей, интерфейса, текста или звука.

Если модель растянула эффект на весь ролик или создала новые предметы,
перегенерируй этот номер. Если только чёрный хвост получился длиннее,
это допустимо: при импорте я обрежу хвост и подготовлю атлас для игры.
Точность тайминга и чистоту фона проверю по полученным MP4; промпт сам
по себе не гарантирует соблюдение каждого ограничения моделью.

Пришли восемь MP4 одним ZIP, сохранив имена.

В пакете нет видео, которые нужно генерировать повторно. До получения
новых MP4 роли показываются встроенными анимациями игры; новые атласы
пока отсутствуют в реестре.

Официальная документация Omni: первый/последний кадр, назначения Image1/2,
форматы и подсказки для единственного непрерывного кадра:
https://ai.google.dev/gemini-api/docs/omni.md

Сборка архива: `scripts/vfx/pack-omni.py`; исходные кадры сохранены без изменений.
