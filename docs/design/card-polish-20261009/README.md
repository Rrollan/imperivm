# Правители, карточки и Строитель — 9 октября

Исправлено по скриншотам пользователя:

- Выбор правителей: пять стартовых и четыре из кейсов в двух подписанных группах. На широком экране все девять монет в одной строке; описание выбранной способности под ними. Посейдон больше не остаётся один в нижней строке.
- Заголовок меню 68 → 62 px, название карты 44 → 42 px (двухстрочное 40 → 38), фракция 44 → 38 px. Размер самих бойцов и разрешение текстур из предыдущей версии сохранены.
- DEFI / DEPIN / NFT / MEME остаются фракцией в руке, стартовой руке, просмотре и на обычном поле. Способность больше не подменяет эту подпись.
- Перерисованы пиктограммы: поднятый рельефный клинок — готовность к атаке, песочные часы с песком — новый боец, опущенный клинок — потраченное действие. Никаких букв Z.
- Розыгрыш: ширина движется равномерно, вертикальная рамка сокращается по трём срезам, арт кадрируется через isotropic cover. Текст и рисунок сохраняют пропорции. К моменту контакта обе стороны уже совпадают с размером бойца на поле. Общий renderer используется в онлайне и против бота; preview использует тот же расчёт. Отмена восстанавливает исходную карту.
- Строитель за 2 приказа восстанавливает 2 казне и **2** самому раненому бойцу (было 1). Ограничения максимума здоровья, выбор по величине ранения / порядку строя и одно применение за ход сохранены. Тексты RU/EN совпадают с движком.

## Проверки

`npm run build`, `npm run test:integrations`, `server/npm test` (12 тестов, включая полный матч и реконнект на 10 секунд), `presentation-check`, `combat-presentation-check`, `deployment-geometry-check`, `arena-actions-check`, `balance-check`.

Новые проверки прогоняют промежуточные размеры всех четырёх рамок, инвариант квадратного пикселя, пропорции арта, подпись фракции и совпадение размеров до / после контакта. Способность проверена для обоих мест, с одинаковыми ранениями, ограничением максимального здоровья, неизменностью врага и сетевым снапшотом.

Браузер: меню 1280 px; стартовая рука и настоящий розыгрыш; остановка тяжёлой карты в полёте и на контакте; горизонтальный телефон 844 × 390 — просмотр, розыгрыш пятого бойца, атака и сила Строителя; меню 390 px; реальный iframe iDos 1280 px. Скриншоты JPEG рядом с этим файлом.
