# Art reproduction recipes

Assets generated with the built-in image generation tool on 9 October 2026. These are regeneration recipes, not a promise of pixel-identical output. PNG transparency belongs to the five coin assets.

## Five rulers

Create one premium game UI medallion on a transparent background. A circular ancient gold coin, crisp beaded rim, sculpted profile relief, restrained depth and one coherent warm gold material. No letters, UI numbers, extra outer decoration, scenery or rectangular card frame. Keep the full coin inside the canvas and the face centred in the inner disc. Readable at 80 px. Roman/Greek collectible illustration, less filigree, strong silhouette; match the existing ruler coin reference.

- Strategist: mature Roman legion marshal, laurel crown, calm determined profile, cuirass, subtle commander insignia.
- Athena: Greek goddess in a elegant crested helmet, calm wise profile, owl motif as a small relief accent.
- Hermes: youthful Greek messenger, winged helmet, light cloak, lively profile, subtle caduceus relief.
- Hephaestus: bearded Greek smith, artisan cap, broad face, hammer insignia in relief; strong sculpted silhouette.
- Poseidon: older bearded sea god, flowing hair, small trident relief, regal profile; use gold rather than blue skin.

Original files: public/ui/heroes/rulers-v2/*.png. Encoded 768px WebP copies preserve alpha and are loaded by the shared heroPortraitPath mapper for both renderers and menus.

## Loading gates

Premium Roman/Greek fantasy card-game loading background, horizontal 16:9. Open massive bronze gates into a warmly lit arena, restrained carved stone and burgundy banners, gold laurel accent, small orange braziers and a quiet teal magical brazier. Rich painterly game illustration with stable architecture and clear central entrance. Dark uncluttered bottom quarter reserved for actual UI text. No people, no lettering, no interface, no numbers, no watermark. Warm amber/bronze with a restrained teal accent; elegant, readable, not overloaded with ornaments.

The runtime uses a 1280px WebP copy of START for faster phone loading. START and END intentionally use the same original illustration for a seamless locked-camera loop. The exact video prompt is in public/ui/loading/arena-gates-v1/PROMPT.txt and the downloadable zip.
