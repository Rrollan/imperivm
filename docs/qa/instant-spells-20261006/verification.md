# Мгновенные заклинания: проверка в браузере

Проверена production-сборка Next на порту 3101 через Codex In-app Browser, обычные кнопки/просмотр и легальные действия. Сценарии получены `createLabGame` из посева через реальные действия, без подмены состояния браузера.

| Карта | URL-параметры | Наблюдение |
|---|---|---|
| Мгновенный заём | hero=degen, seed=3, opening=0 | Ход 9, приказы 5→3, добраны 2 карты, очередь пуста. Добранный Фронтран-бот разыгран в том же ходу; фракционная связка вернула 1 приказ. |
| Обряд восстановления | hero=builder, seed=12, opening=0 | Просмотр содержит «Мгновенно» и «Применить сейчас». Гоплит хотспота восстановлен 2→4 на ходу 9, очередь пуста; остальные здоровые бойцы не получают лечение. |
| Сенатское порицание | hero=builder, seed=21, opening=0 | Охотник за пампом: атака 3→2, ход 9, приказы 5→3, без очереди. |
| Солнечный сапёр | hero=degen, seed=2, opening=0 | Пул стейкинга врага: здоровье 4→2, ход 9, приказы 5→2, без очереди. |
| Переброс признаков | hero=whale, seed=19, opening=0 | Пул стейкинга: 1→2 атаки; Центурион: 2→3. После усиления Центурион атаковал казну противника в том же ходу 9. |

История сообщает «Мгновенное заклинание / Применено сразу», а не постановку в очередь. `npm run smoke` дополнительно проверяет no-op, истощение/смерть от добора, обе стороны, отсутствие повторного применения, четыре отложенных указа и точные цели анимаций.

Снимки: instant-card.jpg, heal-contact.jpg, draw-then-play.jpg. Разовая браузерная проверка не является нагрузочным тестом или доказательством PvP-баланса.
