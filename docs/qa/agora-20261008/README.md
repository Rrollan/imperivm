# Agora After Hours — проверка 8 октября 2026

Проверено на production-сборке локального Next.js, `/collection` и `/arena-lab?hero=builder&opening=1`.

- В каталоге 99 карт, во вкладке новых персонажей 50. Поиск Персефоны и фильтр DePIN (12 новых персонажей) работают. Просмотр показывает настоящие характеристики, эффект выхода, условия ультимейта, конкретного призванного бойца и половинный ответный урон.
- Добавление Персефоны в редактор разрешено; второй экземпляр легендарной блокируется. Пресет Строителя содержит Персефону и ровно 30 законных карт. Сохранённые пользовательские колоды во время браузерной проверки не перезаписывались.
- На 390 × 844 библиотека и просмотр без горизонтального переполнения (scrollWidth 390). Длинное описание прокручивается внутри диалога. Esc закрывает просмотр и восстанавливает управление.
- На 844 × 390 новая карта размещена с клавиатуры, другая перетащена из руки на поле. Цена списывается, недоступные карты исчезают из списка допустимых действий. Касание встроенной кнопки хода передаёт ход AI и возвращает управление после его ответа.
- Из-за короткого экрана в стартовой руке скрывалась кнопка подтверждения. Исправлена высота карт в горизонтальной вёрстке; финальная проверка ниже фиксирует доступность кнопки без прокрутки.
- Ошибок и предупреждений страницы во время проверенных действий не зарегистрировано.

Изображения: `persephone-desktop.png`, `persephone-mobile.png`, `battle-mobile-landscape.png`, `opening-mobile-landscape.png`.

Проверки кода: Next build, strict TypeScript, server build; `npm run smoke`; `npm run test:integrations`; 11 реальных WS-тестов. Последние проверяют полный матч, незаконную чужую атаку, реконнект после десятисекундного обрыва и покупку на реально опустевшей колоде (без изменения серверного состояния тестом), отклонение второй покупки и сокрытие чужой руки.

Расширение: 122 направленных перехода, 90 веток условий, 288 завершённых AI-матчей; матрица всех 99 карт — 144 перехода и 235 валидных эффектов. Эти результаты не заменяют живой PvP-баланс. Зафиксированы Строитель 61,8% и первый ход 60,8% в данной выборке; подробнее в `docs/character-expansion-20261008.md`.

Прямой Phantom, живой Title iDos и подтверждённый Metaplex mint требуют настроенного внешнего окружения; в этом браузере они не проверены. SOL не расходовался. Для развёртывания фронт и WS-сервис обновляются вместе.
