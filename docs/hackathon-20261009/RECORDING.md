## Запись на Mac

1. Открой текущую игру, включи EN и «Не беспокоить», закрой личные вкладки. Разверни окно игры, чтобы интерфейс читался.
2. Пройди маршрут без записи, заранее загрузи карты и подготовь колоду. Убавь игровую музыку.
3. **Shift + Command + 5** → запись экрана или области → **Options / Параметры → Microphone / Микрофон**. Сделай пробу на 10 секунд и послушай голос.
4. Запиши действия с пояснениями. Не нужно выигрывать весь матч. Можно записывать фрагментами и вырезать ожидание загрузки; показанные успехи должны быть настоящими.
5. Останови запись кнопкой в строке меню. Убери начало, конец и длинное ожидание. Горизонтальный кадр; 1080p достаточно.
6. YouTube → **Unlisted / По ссылке**, а не Private. Проверь ссылку в приватном окне без авторизации.

## Короткое описание — EN

IMPERIVM is a browser card battler where imperial Rome meets crypto culture. It features 99 cards, nine rulers, free starter decks, AI training, private duels, and random matchmaking. Solana powers wallet authentication and the mainnet IMP token. Players can exchange SOL for IMP through Jupiter and deposit tokens into their iDos game balance. Five-card packs cost 100,000 IMP, and the marketplace supports player-to-player card trading. A real deposit and balance persistence have been confirmed; live pack settlement and withdrawals are still being tested. The game is published on iDos Games. Current source code is in the rebirth branch.
