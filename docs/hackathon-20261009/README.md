Статус игры/iDos обновлён 10 октября 2026; правила и форма проверены 9 октября. Рабочая ветка для судей — **main**. Это пакет подготовки, а не подтверждение публикации или принятой заявки.

[Текущая iDos-сборка v15](https://si4ips8b.idos.games/v/bld6ce8867df2014a148412f03adffc00d3/index.html#/arena) — Staged, публикация в каталоге ещё не выполнена. Бесплатный случайный PvP и серверное чтение IMP проверены; добавлены явные переводы через Phantom, живой финансовый тест владельца ещё требуется. Денежные ставки ещё не реализованы.

Для записи: [готовое ТЗ Muse на демо 2:58](MUSE-DEMO-BRIEF.md) · [русский и английский текст питча до 2 минут](PITCH-TO-RECORD.md). Запись выполняется в отдельной среде агента; обычный браузер пользователя не использовать.

## Критичный срок и требования

**Colosseum: 13 октября 2026, 11:59 по Алматы, 06:59 UTC.** Это эквивалент 12 октября, 23:59 PDT. Не путать регистрацию с окончательной отправкой проекта. Источники: [правила iDos](https://idosgames.com/contest/solana-superteam-kz/?tab=rules), [объявление Colosseum](https://blog.colosseum.com/metadao-backable-solana-dvp-web3js-v3/).

Правила iDos требуют работающую игру на движке iDos, публикацию в каталоге, осмысленную Solana-интеграцию и **токен игры в Solana mainnet**. Допускается уже существующий проект и собственный ИИ-агент через MCP. Предыдущее ТЗ с devnet для всех компонентов не закрывает требование mainnet-токена. Девнет-бейдж, локальные тестовые IMP и реальный mainnet SPL $IMP — отдельные сущности. [Официальные правила](https://idosgames.com/contest/solana-superteam-kz/?tab=rules).

Для side track нужны полная заявка Colosseum, прохождение его первого фильтра и отдельная заявка [Superteam Earn](https://superteam.fun/earn/listing/superteam-kazakhstan-x-idos-games-side-track). Первый фильтр нельзя считать пройденным по одному факту заполнения полей. Итог iDos зависит от жюри и очков сообщества: 50% / 50%, очки — лайки + 2 × подписчики; действуют правила проверки аккаунтов и антинакрутки. [iDos](https://idosgames.com/contest/solana-superteam-kz/?tab=rules).

Общий KZ-трек — отдельная заявка с собственными условиями; его листинг указывает срок регистрации **8 октября**. Не заявляем участие в нём без подтверждения регистрации/допуска. Это не отменяет отдельные правила iDos. [Листинг KZ](https://superteam.fun/earn/listing/colosseum-crypto-worlds-fair-hackathon-superteam-kazakhstan-track).

## Разделение работы

| Работа | Кто делает | Проверяемый результат |
| --- | --- | --- |
| GitHub, описание продукта, актуальные скриншоты, материалы | Codex | `main`, README, этот пакет и презентация с текущей ареной |
| iDos Title без платных операций | Codex; Жорик проверяет платформу | TitleID, точное имя IMPERIVM, сохранённая конфигурация и доступ через MCP |
| Сборка под iDos | Codex | ZIP с настоящим `index.html` и ассетами игры; тестовый запуск в платформенном iframe |
| Платформенная публикация / деплой | Жорик, после решения владельца | Открываемая страница каталога, рабочие HTTPS API/WS, мобильный landscape и iframe ≤1280 px |
| Mainnet-токен | Пользователь подтверждает Phantom; Codex помогает с конфигом, Жорик проверяет | Mint, сеть mainnet, Explorer, функции/интеграция токена. Сначала фактический quote и параметры, затем отдельное подтверждение |
| Логин, подпись, NFT | Codex готовит путь; пользователь подтверждает кошелёк | Реальный вход, проверенная подпись; отдельный devnet mint и Explorer-ссылка |
| Демо-видео | Muse записывает в своей среде по ТЗ Codex; пользователь загружает | ≤3 минуты работающего продукта, публичная или unlisted ссылка без запроса доступа |
| Питч-видео | Пользователь записывает | **Не более 2:00** по проверенной форме Colosseum; имя/роль/почему строит игру и честный статус интеграции |
| Профиль и команда | Пользователь | Подтверждённые участники, город, роли, прошлый опыт и раскрытие прежней разработки |
| Финальные заявки | Пользователь после общей проверки | Colosseum submit, затем Earn и iDos; ссылки/подтверждения сохранены |

Пополненный Phantom не означает разрешение на выпуск токена, покупку AI-кредитов или оплату. Не назначаем сумму по сообщениям участников: оценки 0.03 SOL / $3–5 не являются текущим тарифом. Проверяем фактический quote в платформе перед действием. Платная генерация iDos не является обязательным способом разработки при использовании собственного агента через MCP.

## Порядок завершения

1. Title SI4IPS8B уже создан и настроен. Main.Decimals=6 подтверждены повторным чтением iDos; прежний блокер устранён. [Точная привязка и текущий статус](../idos/SI4IPS8B-integration.md).
2. v15 успешно загружена в Staged: ZIP 1,19 МБ, распаковка 3,81 МБ. Точные iDos origin разрешены на сервере; случайный PvP на домене iDos и read-only баланс проверены. У v15 проверены загрузка арены и мобильный аккаунт. Исправить категорию App/tools на игровую и проверить пополнение/вывод настоящим Phantom (вывод: текущий минимум возраста аккаунта 7 дней, комиссия 6%). Публикация ещё не выполнена.
3. Mainnet SPL mint подтверждён. До проверки единиц списания и отдельного решения владельца реальные покупки не включать. Дополнительная подпись матча и devnet NFT выключены; они не требуются для обычной тренировки.
4. Владелец проверяет вход своим Phantom, разделение балансов, повторный вход и дуэль с другим устройством. Проверка цены/оплаты только после отдельного решения владельца. Если решено показывать NFT, сначала отдельно проверить реальный devnet mint; текущая заявка не должна обещать готовый NFT или денежный PvP.
5. Проверить зависимости перед выпуском: установленный Next.js 14.2.35 требует отдельной проверки актуальных security advisories. Наличие прошедших игровых тестов не означает отсутствие уязвимостей инфраструктуры.
6. Обновить слайд про iDos фактически завершёнными шагами, записать видео, загрузить материалы и проверить ссылки из приватного окна.
7. Полностью проверить Colosseum, отправить до срока; затем оформить Earn/iDos с прямой ссылкой на проект. Отметить «submitted to Colosseum: Yes» только после реального submit.

До завершения проверок нельзя описывать игру как опубликованную на iDos, оплату как проверенную или NFT как live minted. Mainnet-токен пользователя уже существует и проверен; платное использование ещё не проверено. Всё это можно завершить без пересборки игровой логики.
