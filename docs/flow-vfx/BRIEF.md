## Что прикреплять и какие настройки

Скачать `public/ui/arena-lab/imperivm-flow-vfx-pairs.zip` или открыть `/arena-lab/animation-kit`. В архиве девять отдельных папок. В каждой — ровно три файла, а короткая инструкция находится в `00-START-HERE.txt`.

**16:9, 720p, 4 секунды, First and last.** Например, для видео 01:

1. `01-impact/01-START.png` прикрепить в **Start / First frame**.
2. `01-impact/01-END.png` прикрепить в **End / Last frame**.
3. Весь текст из `01-impact/01-PROMPT.txt` вставить в поле промпта.

Дополнительную картинку-референс не прикреплять. Промпт уже готов. Для видео 02 брать только файлы с номером 02; для остальных — так же. Каждый End — отдельная копия полностью чёрного кадра, чтобы эффект исчез. Все PNG имеют размер 1280×720. Исходники в `frames/` и `prompts/` нужны для сборки пакета; в Flow используются понятные имена из архива.

[Матрица возможностей Flow](https://support.google.com/flow/answer/16352836?hl=en) и [работа с кадрами](https://support.google.com/flow/answer/16353334?co=GENIE.Platform%3DDesktop&hl=en), проверены 05.10.2026: Omni Flash 1.1 поддерживает First and last, 16:9 и длины 4/6/8/10 секунд. Четыре секунды здесь — длина исходника; игра использует только короткий активный участок. Остаток видео должен быть чистым чёрным.

## Художественные ограничения

Камера строго неподвижна, ортографический фронтальный вид. Фон RGB 0,0,0, никаких пола, дымки, серых углов или фона игры. Силуэт не расширяется. Эффект занимает центральные 25–35% изображения; в игре сам световой акцент будет примерно 40–70 px при окне 1280×800. Палитра приглушённая: сталь, старая бронза, слоновая кость, немного бирюзы. Без сияющей белой звезды, золотого вихря, огромного взрыва и длинного шлейфа искр.

Чёрный удаляется аддитивным смешиванием. Поэтому это световые штрихи, а не непрозрачные физические объекты. Кость Дегена должна исчезнуть целиком; проверить её читаемость после сложения цветов. Надписи, статистику, карты, тела и интерфейс не генерировать. Звук из видео в бою не используется: общий таймер запускает существующий SFX в момент результата.

## Приёмка и интеграция

Проверять исходник покадрово, затем поверх настоящего поля. Центр и камера не плавают; акцент не закрывает здоровье; хвост исчезает; один запуск — одно действие. Фактический диапазон выбирается по видео, а не по обещанному в prompt таймингу. Неподходящий стиль перегенерировать.

Боевые клипы превращаются в WebP-атласы 192×108 на кадр, 30 fps, до 300 KB на эффект. В бою нет декодера MP4 и покадровой загрузки видеотекстуры: меняются UV уже загруженного атласа. Одновременно максимум два эффекта. Reduced motion отключает атласы, оставляя числовой результат и нативный отклик. Победа допускает один MP4 до двух секунд внутри окна результата.

```sh
# start/end — секунды фактически выбранного активного фрагмента.
node scripts/vfx/import.mjs 01-impact /path/to/01-impact.mp4 0 0.4
node scripts/vfx/import.mjs 02-builder-heal /path/to/02-builder-heal.mp4 0 0.65
node scripts/vfx/import.mjs 06-victory /path/to/06-victory.mp4 0 1.8
```

Слой: `ArenaSpriteEffects.ts`. Семантика событий: `videoCue.ts`, `abilityCues.ts`. Реестр: `public/ui/arena-lab/fx/manifest.json`. Оригиналы сохранять отдельно. Установлены все восемь боевых атласов и видео победы. Атласы заранее загружаются и остаются в памяти; одновременно показываются максимум два. Повторить проверенный импорт: `node scripts/vfx/import-batch.mjs /path/to/original-videos`.

## Происхождение

Новые изображения созданы встроенным image_gen. Точные prompts и локальные исходники — `frames.json`. Некоторые семейства намеренно используют общий исходный силуэт, а движение различается: лавр восстановления/усиления/победы и печать подтверждения/отмены. Общий конечный кадр — программная одноцветная заливка. `scripts/vfx/frames.mjs` готовит PNG и WebP-превью без обрезки исходников.
