IMPERIVM — 9 ВИДЕО ДЛЯ GOOGLE FLOW

Для каждого видео нужна ОДНА папка, ДВЕ картинки и ОДИН готовый промпт.
Дополнительную картинку-референс прикреплять не нужно.

НАСТРОЙКИ ДЛЯ ВСЕХ ВИДЕО
First and last (первый и последний кадр), 16:9, 720p, 4 секунды.
Все картинки уже имеют размер 1280 × 720. Обрезать их не нужно.

КАК СДЕЛАТЬ ВИДЕО 01
1. Открой папку 01-impact.
2. В Start / First frame прикрепи 01-START.png — картинку с эффектом.
3. В End / Last frame прикрепи 01-END.png — полностью чёрную картинку.
4. Открой 01-PROMPT.txt и вставь ВЕСЬ его текст в поле промпта Flow.
5. Сгенерируй видео. Сохрани его как 01-impact.mp4 и пришли мне.

02: папка 02-builder-heal — восстановление Строителя.

Например, для видео 02 нужны только 02-START.png, 02-END.png
и текст из 02-PROMPT.txt. Сохрани результат как 02-builder-heal.mp4.

Во всех папках End намеренно полностью чёрный: эффект должен исчезнуть.
Промпты уже готовы. Ничего дописывать или составлять самостоятельно не нужно.
Сначала сделай 01 и 02 и пришли результаты: проверим их в игре,
затем продолжим остальные с теми же настройками.
