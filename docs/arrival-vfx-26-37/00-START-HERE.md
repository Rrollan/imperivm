# IMPERIVM — приземления и появления 26–37

Один пакет содержит 12 заданий с готовыми START/END/PROMPT. Сначала сделайте 26 (Фаланга прошивки), 32 (тяжёлый контакт) и 36 (DePIN-попадание), затем остальные.

**Настройки:** Omni Flash, 16:9, 720p, 4 секунды, один результат. Для каждого номера прикрепите его NN-START.png и NN-END.png, затем вставьте весь NN-PROMPT.txt из той же папки. Например: 26-START.png + 26-END.png + 26-PROMPT.txt. START — уже видимый контактный кадр, END — чистый чёрный. Эффект занимает первые 0.55–1.40 секунды; остаток ролика полностью чёрный. Звук добавляет игра.

Если используете Flow Agent, прикрепляйте файлы и давайте AGENT-BATCH-A.txt для 26–31, затем AGENT-BATCH-B.txt для 32–37. Шесть роликов за запрос сохраняют небольшой размер задания. Внутри пакета есть индивидуальные промпты для ручной генерации.

26–32 — контакт с поверхностью: камера строго сверху, без перспективного наклона. Волна расходится в плоскости карты. 33–35 — отдельный стоящий персонаж: стопы всё время остаются на x=50%, y=80%, силуэт и предметы полностью внутри кадра. 36–37 — короткое попадание по центру; траекторию снаряда строит сама игра.

33–35 относятся к будущим Посейдону, Гефесту и Дионису из новых 50 артов. Их игровые способности ещё не реализованы. Остальные ролики также пока являются заданиями на генерацию: наличие START не означает, что видео уже подключено.

Сохраните MP4 под именами из PROMPT.txt и пришлите одним ZIP. Не добавляйте в видео карты, рамки, поле, текст, цифры, музыку и движение камеры. Не растягивайте эффект на все четыре секунды.
