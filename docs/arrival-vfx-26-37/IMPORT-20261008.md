## Воспроизведение импорта

Сохраните полученные MP4 как `26-source.mp4` … `37-source.mp4` в отдельной локальной папке. Реестр проверит SHA-256 перед обработкой:

```sh
node scripts/vfx/import-batch.mjs /absolute/path/to/originals docs/arrival-vfx-26-37/imported-20261008.json
```

Двенадцать WebP-атласов занимают **1 033 912 байт**, каждый ниже лимита 300 КБ. Атласы имеют кадры 256×144, четыре колонки, 30 кадров/с. В игре не декодируются видео; три пока не используемых появления не загружаются заранее. Превью для галереи — 640×360, H.264, без аудио.

Проверены размеры, число кадров, бюджеты, видимость начального контакта/появления после fade-in, чёрное затухание и совпадение длительности превью с атласом. `npm run build`, `npx tsc --noEmit`, `npm run smoke` и проверки боя/геометрии проходят. Матрица покрывает все 49 карт и все семь новых контактов; 1 397 законных действий включают 366 атак без изменения результата движка. Геометрия проверена в 20 вариантах раскладки, на обоих сторонах и в плотных рядах.

Превью: `/ui/arena-lab/imperivm-arrival-vfx-26-37/index.html`. Сетевой протокол и движок не изменены.

В браузере проверен законный розыгрыш Фаланги после хода AI на десктопе 1280×800, затем её появление пятой картой в ряду на горизонтальном телефоне 844×390. Новый контакт остаётся в плоскости карты и сохраняет голубой цвет после исправления смешивания. Горизонтального скролла и ошибок консоли нет.
